# Changelog

## [1.0.0] - 2024

### ✨ Adicionado
- Interface do Cliente para enviar pedidos de músicas
- Interface do Admin/DJ para gerenciar a fila
- Sistema de priorização inteligente (menos vezes cantadas = mais prioridade)
- Cálculo automático de tempo estimado de espera
- Bloqueio automático da fila por horário limite
- Fechamento manual da fila pelo DJ
- Histórico de músicas já cantadas
- Persistência de dados via localStorage
- Design responsivo com Tailwind CSS
- Feedback visual com animações
- Documentação completa

### 🔧 Configurações
- Tempo médio de música: 5 minutos
- Horário limite: 23:00
- Sistema de priorização por rodadas
