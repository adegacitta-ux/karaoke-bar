Este front-end de teste foi substituído

Esta página assumia um schema de fila que eu inventei na Fase 1 (/bares/{barId}/karaoke/fila como map por nome). A auditoria da Fase 2 mostrou que o schema real de produção (v2) é diferente — a fila é um array de pedidos, identificados por id numérico, não por nomeId.

O front-end de teste válido agora é ../fila-v2-sandbox/index.html — uma cópia fiel da interface de fila do v2, adaptada para o projeto Firebase sandbox e com o botão "Furar fila" já integrado ao Worker. Veja ../README.md para o setup completo.
